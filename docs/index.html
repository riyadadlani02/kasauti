Your quantized model passed the benchmark. It still broke.

Every serious deployment shrinks its model, then checks the shrink with a benchmark. On a real mixture-of-experts model at 4-bit, the benchmark said fine. Half of all tokens were being routed to different experts.

Why the usual check misses it

Benchmarks ask short, independent questions. Agents run long trajectories where errors compound instead of averaging out.

Routing is a discrete decision

In a mixture-of-experts model a gate picks which experts handle each token. Quantization nudges the gate's scores, and a token sitting near a decision boundary flips to a different expert entirely. The model is no longer a slightly noisier version of itself — it is running a different computational path. Reconstruction error measures continuous drift and cannot see a discrete flip.

Measured, not argued

27 quantization configs on a real trained MoE: bit-width sweep, component ablations, group sizes, two methods.

Scored by construction

Every probe has mechanical ground truth. No LLM judge — a quantized judge is circular and an API judge adds variance you cannot bound.

Attention damage is routing damage

Quantizing attention alone, touching no expert or gate weight, re-routed 43% of tokens — the gate reads what attention produced.

Cheap enough to run every time

One forward pass per calibration text. Minutes, not the hours a full agentic evaluation costs.

Router flips by layer

The crossing point

Both instruments a practitioner consults stay flat — one improves — while the capabilities an agent depends on fall away beneath them.

Where the flips land

Not randomly. Almost entirely on tokens where the router was already torn between two experts — which is why a cheap check is possible at all.

It searches, and it audits itself

The agent walks each component's bit-width down, scoring candidates on the cheap signal — then periodically stops trusting it and pays for a real probe run.

10 steps · 24 model evaluations · 2 audits rejected the cheap signal

Result: gate 5 · attention 8 · expert 5 — 5.18 mean bits, 68% smaller than BF16, auditing at 0.966 against a 0.95 floor. Uniform 4-bit, the configuration a practitioner reaches for, scores 0.454.

What it actually measures

Four capability probes with ground truth by construction, plus two the agent generated and vetted for itself.

Long-horizon adherence

Constraints stated at step 0, verified up to 30 turns later. Never use this word; end every reply with this line; keep the running count correct.

scored: three independent constraints, fraction satisfied

Format stability under pressure

Structured output requested while the input carries nested delimiters, escaped quotes and injected braces.

scored: does it parse, and are the keys right

Calibration and refusal

Answerable and unanswerable questions mixed. Does abstention survive quantization — the failure most likely to be lost silently.

scored both ways, so blanket refusal cannot game it

Error recovery

A malformed or self-contradicting tool result injected mid-trajectory. Recovery is retrying, not inventing a plausible value.

scored: re-issues the call, asserts nothing it never received

Written by the agent, kept by the vetting

It composed 48 candidate probes across 8 families and kept 2 — the rest were saturated, never moved under damage, or duplicated a probe already in the suite.

kept: lower-case discipline (1.00 → 0.00 under damage) · running total across turns (0.50 → 0.17)

And it remembers

Measurements and audit verdicts persist between runs. A second run repeats no measurement and never re-proposes a config an earlier audit disproved.

run 1: 18 model evaluations · run 2: 0

What the numbers say

Findings from the sweep, including the one that went against the hypothesis.

Accuracy of perplexity as a rule for telling a damaged config from a healthy one. The base rate is also 60% — it is exactly as good as guessing.

Router divergence and layer reconstruction error, on the same split. They tie — which is why the mechanism hypothesis is reported as failed, not confirmed.

About this page. Every number here is a real measurement from the sweep in the repository — 27 quantization configurations on granite-3.0-1b-a400m-instruct, a 1.3B mixture-of-experts model, run on one laptop. Nothing is simulated or interpolated: the demo above reads the same results files the paper does. The 30B-class subjects the method targets need a GPU box, and the capability findings rest on one small model. All thirteen threats to validity are in the repository, not hidden.
